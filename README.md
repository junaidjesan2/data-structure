# Data Structures

This repository contains my work for the Data Structures course in Semester 2. It includes assignments, practice problems, and code from lectures, organized by week and topic.

### assignment- 01
Contains solutions for the first assignment.


### assignment- 02

Contains my solutions for the final exam problems.

### week-01
Covers topics from the first week of the course, including:
- **Time and Space Complexity:** Analyzing the efficiency of algorithms. Understanding how the runtime and memory usage of a program scales with the input size.
- **Vectors:** Dynamic arrays that can grow and shrink in size. Exploring their implementation and common operations.
- **Prefix Sums and Binary Search:** Techniques for efficient query processing on arrays. Applying prefix sums for range sum queries and binary search for finding elements in sorted data.

### week-02
Covers topics from the second week of the course, focusing on:
- **Singly Linked Lists and their operations:** A linear data structure where elements are linked using pointers. Covering insertion, deletion, and traversal operations.

### week-03
Covers topics from the third week of the course, including:
- **Doubly Linked Lists:** A variation of linked lists where each node has pointers to both the next and the previous node. This allows for more flexible traversal and manipulation.
- **STL Lists:** Using the `std::list` container from the C++ Standard Template Library. It provides a doubly-linked list implementation with a rich set of functions.
- **Cycle Detection:** Algorithms to detect cycles in linked lists. A common problem in interviews and a good application of pointer manipulation.

### week-04
Covers topics from the fourth week of the course, focusing on:
- **Stacks:** A LIFO (Last-In, First-Out) data structure. Exploring its implementation using arrays and linked lists, and its applications in solving problems like expression evaluation.
- **Queues:** A FIFO (First-In, First-Out) data structure. Covering its implementation and use cases, such as in breadth-first search algorithms.

### week-05 ( binary tree )
Covers topics from the fifth week of the course, dedicated to:
- **Binary Tree Implementation:** Representing hierarchical data using nodes with at most two children. This section covers the basic structure and creation of binary trees.
- **Operations on Binary Trees:** Implementing fundamental operations like insertion, deletion, traversal (in-order, pre-order, post-order), and searching. These are key for manipulating tree structures.

### week-06 (bst,heap,priority queue and map)
Covers topics from the sixth week of the course, including:
- **Binary Search Trees (BST):** A special type of binary tree where the left child is smaller and the right child is larger than the parent. This property allows for efficient searching, insertion, and deletion operations.
- **Heaps:** A tree-based data structure that satisfies the heap property. Used for implementing priority queues and for efficient sorting (heapsort).
- **Priority Queues:** An abstract data type that provides efficient retrieval of the minimum or maximum element. Often implemented using heaps.
- **Maps and Sets:** Associative containers in the STL. Maps store key-value pairs, while sets store unique elements, both providing fast lookups.
